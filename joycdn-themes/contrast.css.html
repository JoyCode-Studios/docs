5. contrast.css

contrast.css is JoyCDN’s accessibility-first theme, built for users who need maximum clarity, bold visuals, and zero ambiguity. It removes all subtlety — no shadows, no gradients, no rounded corners — just pure contrast and hard edges.

📦 How to Use

Include this in your HTML to apply the theme:

<link rel="stylesheet" href="https://cdn.joycode.co.uk/themes/contrast.css">

🎨 Visual System

  • Font: Segoe UI, sans-serif
  • Background: #ffffff (white)
  • Text: #000000 (black)
  • Accent: #0000ff (blue), hover: #000099
  • Card background: #ffffff
  • Border: #000000, 2px solid
  • Radius: 0 (no rounding)
  • Shadow: none

🧱 Typography

All headings h1–h5 are bold, underlined, and use the same black text color as body copy. Font size is increased and line height is 1.8 for readability.

🔘 Buttons

Buttons are bold, rectangular, and unmistakable. They use a blue background with white text, a thick black border, and no rounding. On hover, the blue darkens to #000099. 

<button class="button">High Contrast Button</button>

📦 Cards

Cards are white with a 2px black border, no shadow, and no radius. They’re designed to be unmistakably separate from the background.

📝 Forms

Inputs, selects, and textareas are styled with:

  • Black 2px borders
  • White background, black text
  • Focus state: 3px solid blue outline
  • No border radius

📢 Alerts

Each alert type uses strong background and text colors:

  • .alert-info: #e6f0ff background, #000066 text
  • .alert-success: #e6ffe6 background, #006600 text
  • .alert-error: #ffe6e6 background, #990000 text

📐 Layout Helpers

Includes all standard JoyCDN utilities:

  • .flex, .grid, .center, .hidden
  • All spacing and alignment helpers are preserved

🧪 Best Practices

  • Use semantic HTML and label all inputs clearly
  • Use .button, .card, and .alert classes for consistent accessibility
  • Test your site with screen readers and keyboard navigation
  • To apply this theme, manually update your <link> tag
