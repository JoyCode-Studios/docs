3. dark.css

dark.css is the official dark mode theme in the JoyCDN collection. It’s designed for low-light environments, high-contrast readability, and a sleek, modern aesthetic. It pairs beautifully with minimal UIs, developer tools, and documentation sites.

📦 How to Use

To apply dark.css to your site, include this in your HTML:

<link rel="stylesheet" href="https://cdn.joycode.co.uk/themes/dark.css">

🎨 Color Palette

The theme uses a dark-neutral base with soft accents:

  • --color-bg: Deep charcoal background
  • --color-text: Light gray or off-white text
  • --color-accent: Muted blue or teal for buttons and links
  • --color-card: Slightly lighter panels for cards and containers
  • --color-border: Subtle outlines for inputs and dividers

🧱 Base Styling

The theme applies a dark background to the body, adjusts text color for contrast, and preserves the same spacing, font stack, and layout helpers as joy.css.

🔘 Buttons

Buttons use the accent color for background and white text. On hover, the accent darkens slightly. The button shape, padding, and font weight remain consistent with other themes.

📦 Cards

Cards use a slightly elevated background color to distinguish them from the page. They retain the same border radius and shadow as in joy.css, but with darker tones.

📝 Forms

Input fields, selects, and textareas are styled with dark backgrounds, light text, and soft borders. Focus states use the accent color to indicate interactivity.

📢 Alerts

Alert boxes are adapted for dark mode with adjusted background and text colors:

  • .alert-info: Navy background with light blue text
  • .alert-success: Dark green background with mint text
  • .alert-error: Deep red background with soft pink text

📐 Layout Utilities

All layout helpers from joy.css are preserved:

  • .flex, .grid, .center, .hidden
  • Spacing and alignment utilities remain unchanged

🧪 Best Practices

  • Use semantic HTML for optimal styling and accessibility
  • Ensure sufficient contrast for custom elements
  • Use .card and .button classes for consistent UI
  • To switch to dark.css, manually update the <link> tag in your HTML
