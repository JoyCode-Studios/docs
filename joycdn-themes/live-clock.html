8. Live Clock

The Live Clock widget is a lightweight, embeddable component that displays the current time in real-time. It’s perfect for dashboards, landing pages, or any site that wants to show the time without writing JavaScript.

📦 How to Use

Embed the clock anywhere in your HTML using an <iframe>:

<iframe src="https://cdn.joycode.co.uk/clock/live-clock.html"
        style="border: none; width: 800px; height: 500px;"></iframe>

You can also adjust the size of the clock by changing the width and height attributes in the iframe tag.

🕒 Features

  • Displays current time in 24-hour format
  • Updates every second
  • Styled with joy.css for clean integration
  • No JavaScript required on your end
  • Fully responsive and iframe-safe

🎨 Styling

The clock uses a minimal layout with centered text, a soft background, and a monospaced font. You can override its appearance by wrapping the iframe in a styled container or using transform and scale to resize it.

📐 Sizing Tips

  • Default size: 800px × 500px
  • To scale up, increase width and height proportionally
  • Use max-width: 100% for responsive layouts

🧪 Best Practices

  • Use only one clock per page to avoid redundancy
  • Place it in headers, footers, or sidebars for visibility
  • Test on mobile to ensure it scales properly
