1. Getting Started

Welcome to JoyCDN — a lightweight, zero-config CDN for beautiful themes and embeddable widgets. Whether you're building a personal site, a documentation hub, or a creative tool, JoyCDN gives you instant access to clean CSS themes and plug-and-play components — no build tools, no setup, no nonsense.

✨ What Is JoyCDN?

JoyCDN is a collection of CSS themes and JavaScript widgets hosted on a fast, globally distributed content delivery network. It’s designed to help you:

  • Style your site with beautiful, accessible themes like joy.css, dark.css, and retro.css
  • Embed live clocks, countdowns, and timers with a single line of HTML
  • Build fast, modern UIs without frameworks or dependencies

🚀 Quick Start

To apply a JoyCDN theme to your site, just include this in your HTML:

<link rel="stylesheet" href="https://cdn.joycode.co.uk/themes/joy.css">

To embed a widget like the Live Clock:

<iframe src="https://cdn.joycode.co.uk/clock/live-clock.html" style="border: none; width: 200px; height: 60px;"></iframe>

📁 CDN Structure

JoyCDN is organized into two main directories:

  • /themes/ – Contains all CSS themes (e.g. joy.css, dark.css)
  • /clock/ – Contains embeddable widgets like live-clock.html and ny-timer.html

🧪 Browser Compatibility

JoyCDN themes are tested in some modern browsers (The only tested is currently Chrome). They use no JavaScript frameworks and rely only on native HTML, CSS, and minimal JS.

🧩 Use Cases

  • Documentation sites
  • Landing pages
  • Portfolio projects
  • Internal tools and dashboards
  • Educational or experimental sites

📦 CDN Hosting

All files are hosted on cdn.joycode.co.uk and served over HTTPS. You can link directly to any file without needing to download or self-host.
