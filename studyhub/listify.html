Listify Integration

StudyHub includes built‑in integration with Listify, a cloud‑based notes and list manager created by JoyCode Studios. While StudyHub’s core tools use localStorage, Listify provides optional cloud sync, multi‑device access, and account‑based storage powered by Cloud Firestore.

What Is Listify?

Listify is a standalone productivity tool available at:

https://listify-ejc.pages.dev

It allows you to create:

  • cloud‑saved notes
  • checklists
  • task lists
  • multi‑device synced documents

Listify requires an account and stores your data securely in Cloud Firestore.

How StudyHub Connects to Listify

StudyHub includes a dedicated Listify button in the dashboard and sidebar. Clicking it opens Listify in a new tab, allowing you to access your synced notes and lists alongside your StudyHub tools.

StudyHub does not store your Listify login information — authentication happens entirely on Listify’s side.

When to Use Listify Instead of StudyHub Notes

Use StudyHub’s built‑in Notes system when you want:

  • offline access
  • fast, simple note‑taking
  • local‑only storage

Use Listify when you need:

  • cloud sync across devices
  • an account‑based system
  • long‑term storage
  • lists that sync between phone and computer

Data Separation

StudyHub and Listify store data independently:

  • StudyHub → localStorage (offline, device‑specific)
  • Listify → Cloud Firestore (online, synced)

This means deleting StudyHub data does not affect Listify, and vice‑versa.

Why StudyHub Uses Both

StudyHub is designed to be fast, offline‑friendly, and simple. Listify is designed for cloud sync and long‑term storage. Together, they create a flexible study workflow:

  • quick notes → StudyHub
  • important lists → Listify
  • daily tasks → StudyHub
  • multi‑device notes → Listify
